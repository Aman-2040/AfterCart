# Backend

Java + Spring Boot REST API and application source of truth.

Responsibilities:
- Product and retailer listing APIs
- Payment preferences (non-sensitive metadata only)
- Offer eligibility and deterministic deal calculation
- Orders, agent tasks, task steps and approvals
- Communication with the Python AI service

Never store full card numbers, CVV, PINs or banking credentials.
Add local setup instructions and `.env.example` when initialized.
